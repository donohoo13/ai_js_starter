Interview the user relentlessly about every aspect of this request/idea until we reach a shared understanding. Walk down each branch of the design tree, resolving dependencies between decisions one-by-one. For each question, provide your recommendation along with the reasoning behind it.

Explore the project to verify the user's assertions and understand the current state of the codebase before each question. Attempt to correct any misunderstandings about how the code currently works. Be specific — reference files and patterns you discovered to the common understanding.

Ask the questions one at a time.

Do not move on from a topic until the user has given a direct confirmation or answer without ambiguity.
