---
name: grill-me
description: Interview the user relentlessly about a plan or design until a shared understanding is reached. Use when user wants to discuss a new request, idea, concept, issue, or stress-test a plan. Grilling sessions are best had before an implementation and should be used when the user uses any 'grill' trigger phrases.
---

Interview me relentlessly about every aspect of this until we reach a shared understanding. Walk down each branch of the design tree, resolving dependencies between decisions one-by-one. For each question, provide your recommendation along with the reasoning behind it.

If a _fact_ can be found by exploring the codebase, look it up rather than asking me and attempt to verify my assertions as factual. The _decisions_, though, are mine — put each one to me and wait for my answer. Attempt to correct any misunderstandings about how the code currently works as it relates to my request. Be specific — reference files and patterns you discovered to the common understanding.

Ask the questions one at a time to avoid confusion in order of magnitude to help shape the grilling session early. Asking multiple questions at once is bewildering.

Do not move on from a topic/question until the user has given a direct confirmation or answer without ambiguity and the shared understanding has been reached.
